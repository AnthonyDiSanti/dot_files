- What’s in progress: Clipboard/register unification is active on `feature/clipboard`. The approach is a small repo-owned text wrapper, `dotfiles-clipboard copy|paste|status`, that bridges app-local buffers/registers to real platform clipboards. Clipboard v1 targets only macOS and Ubuntu under WSL / Windows because those are the environments available for direct testing. macOS support uses `pbcopy` / `pbpaste`; WSL support now uses Microsoft-native `clip.exe` for copy plus PowerShell `Get-Clipboard -Raw` for paste, with CR stripping centralized in the wrapper. zsh vi-mode yank/delete/change/substitute, paste-time CUTBUFFER refresh, visual selection paste, and tmux clipboard actions call the wrapper only when a provider is available. Real WSL smoke testing remains before considering v1 complete; OSC 52 and Linux desktop providers are deferred.
- What’s broken / flaky: No known issues.
