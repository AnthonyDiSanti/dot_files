# Agent instructions

- Source: `agents/skills/`, `agents/skills/_models/`, `agents/official-docs/`, `agents/model-guidance/`, `home/.codex/skills/`
- Why it matters: repo-managed skills and prompt guidance shape future agent behavior across Codex and other harnesses.
- When to consult: creating or tuning skills, updating AGENTS instructions, comparing model-specific prompt guidance, or debugging why an agent behaves differently after a model upgrade.
- Key points: Canonical skills live under `agents/skills/`; harness deployment paths live under `home/` as symlink nodes. Authoritative cached vendor docs live under `agents/official-docs/` and should not be hand-edited. Repo-authored generic model guidance lives under `agents/model-guidance/` and should cite official docs while preserving concrete adapted examples that apply across skills. Skill-specific model notes live under `agents/skills/_models/<skill>-<model>.md`. The first guidance set covers GPT-5.5, Claude Opus 4.7, and Claude Opus 4.6. GPT-5.5 guidance emphasizes outcome-first prompting, source-backed versus creative drafting boundaries, and explicit visual/image-detail expectations. Claude guidance emphasizes explicit effort/tool triggers, state management across long agentic work, file-grounded codebase claims, and restraint around temporary scaffolding/subagents. The `commit-prep` skill is currently tuned for GPT-5.5: outcome-first, compact, explicit about git index ownership, full-dirty-tree scope by default, and focused on success criteria rather than a long procedural script.
- Gotchas: Current model prompt guidance is versioned and changes over time. Re-check official docs before retuning a skill for a named model. Restart Codex after changing installed skill metadata or deployment shape.
- Verification: `codex debug prompt-input 'test' | rg 'commit-prep|Available skills|skills/commit-prep' -C 2` confirms fresh Codex prompt discovery; use markdown lint/format checks when adding prompt-guide docs.
