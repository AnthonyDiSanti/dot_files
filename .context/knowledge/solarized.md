# Solarized assets (no submodule)

- **Vim:** `lifepillar/vim-solarized8` in `home/.vimrc` / `~/.vim/plugged` — not `altercation/vim-colors-solarized`.
- **Ghostty:** `home/.config/ghostty/config` → `~/.config/ghostty/config` — Solarized Dark (canonical hex from upstream Xresources); `alpha-blending = native` (Display P3 on macOS); `palette-generate = true` for a Solarized-derived 256-color cube; `macos-titlebar-style = transparent` so window chrome matches base03.
- **iTerm2:** `home/Library/Application Support/iTerm2/DynamicProfiles/solarized-dark.json` → `~/Library/Application Support/iTerm2/DynamicProfiles/solarized-dark.json` — dynamic profile named `Solarized Dark (dotfiles)`. It uses the same canonical ANSI mapping as Ghostty, disables bright-bold color substitution, and sets minimum contrast to zero so iTerm2 does not adjust Solarized colors. Dynamic profiles appear in the normal iTerm profile list with a `Dynamic` tag; `Dynamic Profile Parent Name` only selects inherited settings. Run `settings/iterm2.sh` to write iTerm2's `Default Bookmark Guid` to this profile's GUID and set `TmuxUsesDedicatedProfile=false` so `tmux -CC` inherits the connecting session profile. The local iTerm `tmux` profile was only a copy of `Default` with `Has Hotkey=false`, so disabling the dedicated tmux profile did not discard meaningful tmux-specific behavior.
- **Repo:** We removed the **`settings/solarized`** git submodule (full upstream monorepo). It was reference-only and unused by bootstrap. Restoring it is optional: Ghostty/iTerm2 theming does not require the submodule because the needed hex values are inlined.
- **When to consult:** You need Terminal.app / Xresources / other app-specific assets — clone [altercation/solarized](https://github.com/altercation/solarized) or use app-specific docs; see `settings/README.md`.
